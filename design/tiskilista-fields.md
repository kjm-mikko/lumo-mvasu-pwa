## Authoritative sources

- **Default ListView** (NavigationItems §`Item Id="Tiskilista"`):
  `Tiskilista_ListView_DetailView` — the split list+preview view.
- **Default DetailView**: not declared on the `<Class Name="xVasu.Data.Asutus.Tiskilista">`
  block, so the convention name `Tiskilista_DetailView` would apply
  generically. The **list's `MasterDetailView`** points instead at
  `Tiskilista_DetailView_Simple` (the preview-pane content) — that is
  the layout the mobile detail screen should mirror.
- **Calculated `OwnMember`**: `DistanceFrom` (`Type="System.Double"`,
  `Expression="GetDistance(Latitude,Longitude)"`,
  `DisplayFormat="{0:# ##0.0} km"`). Used as the `DistanceFromAlias`
  column when the user has lat/lon.
- **Hard ListView filter** (already-on scope): `[SopimusTila] = 'Irtisanottu' And [laji] = 'Asuinhuoneisto'`
  — the legacy XAF list shows ONLY irtisanotut asuinhuoneistot. The
  PWA relaxes this and exposes `laji`/`SopimusTila` as filter
  dimensions instead.
- **Visual rule**: `[vapautuu] <= Today()` highlighted with light blue
  background — apartments past their release date.

## Filter dimensions for the PWA

Currently exposed:

- `q` — free-text search (katuosoite / kunta / KuntaAlue /
  Postitoimipaikka + numeric kptunnus / huonetunnus — see
  `TiskilistaQueryService.BuildCriteria`)
- `status` — exact `Tila`
- `lajit` — multi-select `laji`
- `scope` — own areas vs. all (BranchCode-driven)
- `sortBy` — vapautuu / osoite / vuokra / distance

Suggested next-up (each maps to a column in the ListView):

| Dimension | Column / Property | Filter shape |
|---|---|---|
| Tyyppi | `tyyppi` (string) | Free-text or distinct-list multi-select |
| Kunta | `kunta` (string) | Multi-select dx-tag-box of distinct values |
| Kaupunginosa | `KuntaAlue` (string) | Multi-select dx-tag-box, scoped by kunta |
| Pinta-ala | `neliot` (double) | Range slider (min / max m²) |
| Vapautumispäivä | `vapautuu` (DateTime) | Date-range picker |
| Kuvaustarve | `Huoneisto.OnKuvausTarve` (bool) | Toggle / chip |
| Sopimustila | `SopimusTila` (string) | Already-on filter relaxed → multi-select |
| Lumo.fi | `Huoneisto.LumoOneEnabled` (bool) | Toggle |
| Isannoitsijä | `Huoneisto.Talousyksikkö.IsannoitsijaAlias` (string) | Multi-select |

Distinct-value lookups (kunta, kaupunginosa, isännöitsijä) need a
helper endpoint that runs `SELECT DISTINCT … FROM Tiskilista` with the
same scope criteria as the list, otherwise the filter would offer
values the user can't actually see.

## Mobile mapping recommendation

### Card (mobile list row)

Top six high-signal columns from the ListView:

1. **Hero** — `katuosoite` (= title), `Tila` badge, optional Lumo.fi pill
2. **Subtitle** — `kunta` · `KuntaAlue`
3. **Stats row** — `tyyppi` · `neliot` m² · `kerrostieto`
4. **Footer** — `vuokra` €/kk, `vapautuu` (highlight if past Today)
5. **Distance** — `DistanceFromAlias` km (when location consent granted)
6. **Badges** — `OnKuvausTarve` "Kt" warn pill, `Vuokraovi`, `Prio` if non-default

(Already broadly matches the current
[`tiskilista-list.component.ts`](../src/mVasu.Pwa/src/app/features/tiskilista/tiskilista-list.component.ts)
layout. Missing: `SAP_Palveluluokka` (Prio), `Isannoitsija` aliases.)

### Detail

Two stacked cards on mobile, ordered to match `Tiskilista_DetailView_Simple`:

1. **Sijainti & vuokra** — `katuosoite`, `kunta`, `KuntaAlue`,
   `vuokra`, `vapautuu`, `poismuutto`, `VapautuuAsiakkaalta`
2. **Huoneisto** — `tyyppi`, `neliot`, `Tila`, `kerrostieto`, `hissi`,
   `parveke`, `sauna`
3. **Markkinointi** — `LumoOne`, `Vuokraovi`, `OnKuvausTarve`,
   `SAP_Palveluluokka`, `BrochureUrl`
4. **Hallinta** — `Isannoitsija`, `Tarkastustila`, `Muistio`
5. **Remontti** — `RemontinAlkamispaiva`, `RemontinPaattymispaiva`,
   `Remonttityyppi`

Action sheet (bottom): **Avaa Lumo Verkossa** · **Lisää remontti** ·
**Pikavaraus** · **Laske tiskilista** · (overflow: navigation, share).
